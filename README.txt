SLOW ARCHIVE — SEMANTIC HTML VERSION

Files:
- index.html: organized semantic HTML (no JavaScript)
- style.css: original styling with small resets for semantic lists/paragraphs
- assets/: original source images, footer icons, and audio

HTML structure:
1. <header> for the site introduction
2. <main> containing an ordered list of source cards
3. One <dialog> per source, with an <article> and <header>
4. <section> and <ul> for reading links, <ul> for research tags
5. <footer> with the portfolio link and a native <details> music player

The <audio> player is the requested exception to the course elements.
The portfolio URL is still a placeholder: change https://example.com/ in index.html.

To preview, open index.html in Chrome or another modern browser. <dialog> uses command / commandfor with no scripts.
